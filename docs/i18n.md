# Idioma EN / ES

Selector en el navbar con dos botones accesibles y estado `aria-pressed`. Español es el idioma inicial; la selección se guarda con la clave `portfolio-language`. La traducción funciona también cuando el almacenamiento local está bloqueado.

`LanguageService` comparte el idioma mediante una señal Angular. `TranslatePipe` actualiza textos, atributos y mensajes dinámicos sin recargar la página ni cambiar las rutas. El servicio actualiza también `html[lang]`, título, descripción y salto al contenido. No se utiliza ningún servicio externo ni se instalan dependencias.

Los nombres propios y las tecnologías no se traducen. Las traducciones del contenido y de las etiquetas editoriales están en `language.service.ts`. El CSS del manifiesto ajusta su escala en español para conservar las tres líneas sin desbordar.

Validación: cambio inmediato, persistencia tras recarga, Home, About, detalles de proyectos, etiquetas accesibles y avisos; navbar en 320, 390, 640, 768 y 1440 px, sin desbordamientos. Menú móvil y cierre con Escape comprobados en ambos idiomas. Script local: `.local/review-languages.mjs`.
